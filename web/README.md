# Camera Planner 独立场景工作台

此目录保存已上线的独立 Web 工作台：场景铺满操作区，工具独立显示，悬停查看说明；选中元素后显示可拖动、可固定的属性浮层。三维操作支持三轴、三平面移动、圆环和自由旋转，以及世界／局部坐标切换。

## 本地运行

需要 Node.js `>=22.13.0`。工作台的运行、构建和测试只使用 Node 内置能力，**无需安装依赖**。

从仓库根目录执行：

```sh
npm run workspace:dev
npm run workspace:build
npm run workspace:test
```

也可以在 `web/` 中分别执行 `npm run dev`、`npm run build`、`npm test`。开发服务默认地址为 `http://127.0.0.1:4173/planner/`；可通过 `PORT` 更改端口。

构建产物位于 `web/dist/`，可整体发布到静态服务器或任意站点子目录。根 `index.html` 通过相对地址打开 `web/public/planner/index.html`，适用于从仓库根目录发布 GitHub Pages；构建后的 `web/dist/index.html` 则通过 `./planner/index.html` 打开工作台。请通过 HTTP 服务访问，避免直接以 `file://` 打开 ES 模块。

## 使用与保存

- `G` 移动、`R` 旋转、`S` 缩放；变换过程中用 `X / Y / Z` 限轴，`Shift` 加轴键限定相应平面，`Esc` 取消。一次完成的变换对应一次撤销记录。
- `K` 为所选摄影机或角色记录当前显示姿态，空格播放或暂停；取景器支持彩图和深度显示。
- 场景自动保存在当前浏览器本地，不会自动同步到其他浏览器或设备。跨设备或长期保存时，请通过“交付”下载完整场景 JSON；导入使用当前工作台的完整场景格式。
- “交付”还提供运镜参考 JSON、场景 PNG 截图与分镜一览。镜头换算可从顶部、摄影机属性或交付面板进入。

## 数值镜头基准

镜头换算支持焦段、主体距离、景别预设三向互算，光圈与对焦独立设置。默认采用虚拟有效画幅宽 **36 mm**、横向 **16:9**（有效画幅高 **20.25 mm**）、直立主体高度 **1.70 m**；以上基准和取景中心均可调整。景别是构图预设，并非唯一的光学标准。

**180°模式只描述中心观看窗口的等效镜头。** 普通直线透视的焦段公式不能代表完整半球投影。实际鱼眼或等距柱状全景仍需确定投影和观看窗口；生成模型对数值提示的响应需要样片校准。近摄、明显倾斜姿态、畸变和镜头呼吸不在一阶构图估算内。

## 与根 npm 组件的关系

这是独立工作台，版本为 `0.2.0`。根目录的 `@muraguchi/camera-planner` npm 组件仍保留原有包名、版本、`main / exports / types` 接口、构建命令，以及 `src/`、`demo/`、`dist/`。独立工作台的升级不表示这些旧组件源码已同步重构；集成 npm 组件仍应遵循根目录的组件接口说明。

`public/planner/` 中保留可读的工作台、镜头计算与状态模块，并复用 `assets/planner-core-v6.js` 中已打包的三维运行时。Three.js TransformControls 及其 MIT 许可位于 `public/planner/vendor/`。修改后运行测试和构建，再发布完整的静态产物。
